| Function | Purpose | Example |
| --- | --- | --- |
| len() | Length/count items | len("hello") → 5 |
| range() | Create sequence of numbers | range(5) → 0,1,2,3,4 |
| sorted() | Sort items | sorted([3,1,2]) → [1,2,3] |
| reversed() | Reverse order | reversed([1,2,3]) → [3,2,1] |
| enumerate() | Loop with index | for i, x in enumerate([a,b]): |
| zip() | Combine lists | zip([1,2], [a,b]) → (1,a), (2,b) |
