| Function | Purpose | Example |
| --- | --- | --- |
| abs() | Absolute value | abs(-5) → 5 |
| round() | Round to nearest | round(3.7) → 4 |
| pow() | Power/exponent | pow(2, 3) → 8 |
| min() | Find minimum | min(3,1,5) → 1 |
| max() | Find maximum | max(3,1,5) → 5 |
| sum() | Add all numbers | sum([1,2,3]) → 6 |
