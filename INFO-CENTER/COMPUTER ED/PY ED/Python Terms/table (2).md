| Function | Purpose | Example |
| --- | --- | --- |
| str() | Convert to text | str(123) → "123" |
| int() | Convert to whole number | int("123") → 123 |
| float() | Convert to decimal | float("3.14") → 3.14 |
| bool() | Convert to True/False | bool(1) → True |
| list() | Convert to list | list("abc") → ['a','b','c'] |
| tuple() | Convert to tuple | tuple([1,2,3]) → (1,2,3) |
| dict() | Convert to dictionary | dict([('a',1)]) → {'a':1} |
| set() | Convert to set | set([1,1,2]) → {1,2} |
