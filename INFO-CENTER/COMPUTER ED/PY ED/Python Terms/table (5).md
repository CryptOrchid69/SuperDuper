| Function | Purpose | Example |
| --- | --- | --- |
| len() | Length of string | len("hello") → 5 |
| upper() | Make uppercase | "hello".upper() → "HELLO" |
| lower() | Make lowercase | "HELLO".lower() → "hello" |
| strip() | Remove spaces | "  hello  ".strip() → "hello" |
| split() | Split into list | "a,b,c".split(",") → ['a','b','c'] |
| join() | Combine list | ",".join(['a','b']) → "a,b" |
| replace() | Replace text | "hello".replace("l","x") → "hexxo" |
| find() | Find position | "hello".find("l") → 2 |
