| Function | Purpose | Example |
| --- | --- | --- |
| type() | Get type of object | type(5) → <class 'int'> |
| dir() | List properties | dir(my_object) |
| getattr() | Get attribute | getattr(obj, "name") |
| setattr() | Set attribute | setattr(obj, "name", "John") |
| hasattr() | Has attribute? | hasattr(obj, "name") |
