| Symbol | Name | Purpose | Example |
| --- | --- | --- | --- |
| + | Plus | Addition | 5 + 3 = 8 |
| - | Minus | Subtraction | 5 - 3 = 2 |
| * | Asterisk | Multiplication | 5 * 3 = 15 |
| / | Slash | Division | 6 / 2 = 3 |
| // | Double Slash | Integer Division (no decimals) | 7 // 2 = 3 |
| % | Percent | Modulo (remainder) | 7 % 2 = 1 |
| ** | Double Asterisk | Exponent/Power | 2 ** 3 = 8 |
