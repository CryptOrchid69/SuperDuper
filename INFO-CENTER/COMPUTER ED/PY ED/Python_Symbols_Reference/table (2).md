| Symbol | Name | Purpose | Example |
| --- | --- | --- | --- |
| = | Equals | Assigns a value to a variable | name = "John" |
| += | Plus Equals | Add and assign | x = 5; x += 3 → x = 8 |
| -= | Minus Equals | Subtract and assign | x = 5; x -= 2 → x = 3 |
| *= | Times Equals | Multiply and assign | x = 5; x *= 2 → x = 10 |
| /= | Divide Equals | Divide and assign | x = 10; x /= 2 → x = 5 |
| //= | Int Divide Equals | Integer divide and assign | x = 7; x //= 2 → x = 3 |
| %= | Modulo Equals | Modulo and assign | x = 7; x %= 3 → x = 1 |
| **= | Power Equals | Exponent and assign | x = 2; x **= 3 → x = 8 |
