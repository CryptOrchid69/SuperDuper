| Symbol | Name | Purpose | Example |
| --- | --- | --- | --- |
| == | Double Equals | Is equal to? | 5 == 5 → True |
| != | Not Equals | Is NOT equal to? | 5 != 3 → True |
| < | Less Than | Is smaller than? | 3 < 5 → True |
| > | Greater Than | Is larger than? | 5 > 3 → True |
| <= | Less Than or Equal | Smaller or same? | 5 <= 5 → True |
| >= | Greater Than or Equal | Larger or same? | 5 >= 5 → True |
