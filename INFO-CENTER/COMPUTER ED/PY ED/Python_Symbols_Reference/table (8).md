| Symbol | Name | Purpose | Example |
| --- | --- | --- | --- |
| _ | Underscore | Variable name / Ignored value | first_name = "John" |
| ... | Ellipsis | Placeholder / End of sequence | def func(): ... |
| -> | Arrow | Function return type hint | def add(x) -> int: |
| := | Walrus | Assign and use (Python 3.8+) | if (n := len(x)) > 10: |
