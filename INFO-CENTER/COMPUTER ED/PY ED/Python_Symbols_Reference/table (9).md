| Don't Confuse | Meaning | Example |
| --- | --- | --- |
| = vs == | = assigns, == compares | x = 5 (assign) vs x == 5 (compare) |
| and vs , | and combines conditions, , separates items | x > 5 and y < 10 vs print(a, b, c) |
| () vs [] | () for functions, [] for lists | print() vs my_list[0] |
| ' vs " | Both work for strings (same thing) | "hello" = 'hello' |
| : vs ; | : starts code blocks, ; ends statements | if x: vs x = 5; |
