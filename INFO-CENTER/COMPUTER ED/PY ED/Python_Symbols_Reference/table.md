| Symbol | Name | Purpose | Example |

| --- | --- | --- | --- |

| () | Parentheses | Calls a function; groups expressions | print("Hello") |

| [] | Square Brackets | Creates/accesses lists; indexes items | my_list[0] |

| {} | Curly Braces | Creates dictionaries; sets | {"name": "John"} |

| : | Colon | Starts a code block (if, for, def, etc.) | if x > 5: |

| , | Comma | Separates items/arguments | print("a", "b", "c") |

| . | Period/Dot | Accesses object properties/methods | name.upper() |

| ; | Semicolon | Separates statements (rarely used) | x = 5; y = 10 |

| # | Hash | Starts a comment (ignored by Python) | # This is a comment |

| \\ | Backslash | Line continuation | x = 1 + 2 + \\ |

| ' or " | Quotes | Enclose text/strings | "Hello" or 'World' |

| ''' or """ | Triple Quotes | Multi-line strings | """Long text""" |

| @ | At Symbol | Decorators (advanced) | @property |
