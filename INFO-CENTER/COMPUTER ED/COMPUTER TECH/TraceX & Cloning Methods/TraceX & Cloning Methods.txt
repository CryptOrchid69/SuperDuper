OPTION #2: 

Restarting the Modem/Router (Dynamic IP Renewal)

This is the most common method for home internet users with a dynamic IP.

How it works

Many ISPs assign IP addresses using DHCP leases. When the modem reconnects, the ISP may:

give the same IP back,
or assign a new one.
Steps
Save any work using the internet.
Turn off:
modem,
router,
or modem/router combo.
Unplug power from the wall.
Wait:
sometimes 5–10 minutes,
sometimes several hours if the ISP uses long leases.
Plug the modem back in.
Wait for internet lights to stabilize.
Reconnect your router if separate.
Check your new public IP.

Useful IP checker sites:

WhatIsMyIP.com
IPChicken
Notes
Some ISPs almost always reassign the same IP.
Others rotate frequently.
Fiber ISPs often keep addresses longer.

Changing/Cloning the Router WAN MAC Address

Important Technical Concepts
Dynamic IP

Changes periodically or after reconnecting.

Static IP

Manually assigned and usually does not change.

CGNAT

Many users share one public IP.

DHCP Lease

Temporary assignment of an IP address.

WAN vs LAN
WAN = internet-facing public IP.
LAN = local/private network addresses.
