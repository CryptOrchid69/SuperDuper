FILE AND FOLDER MANAGEMENT COMMANDS
APPEND
Description: Allows programs to open files in a different directory as if they're in the current one.

Basic Syntax:



APPEND [[drive:]path[;[drive:]path]...] [/X[:ON|:OFF]] [/PATH:ON|:OFF] [E:nnnnn]
Common Usage Examples:

APPEND C:\DATA – Tells the system to search the C:\DATA directory for files
APPEND C:\DATA;D:\FILES – Appends multiple paths separated by semicolons
APPEND /X:ON – Enables the APPEND command to search paths for executable files
APPEND /PATH:ON – Allows the PATH environment variable to work with APPEND
APPEND (with no parameters) – Displays currently appended directories
APPEND ; – Clears all appended paths
Important Notes: This command is deprecated in modern Windows versions and primarily works in MS-DOS and 32-bit Windows environments.

ASSOC
Description: Displays or changes file type associations for specific file extensions.

Basic Syntax:



ASSOC [.ext[=[fileType]]]
Common Usage Examples:

ASSOC – Displays all file type associations on your system
ASSOC .txt – Shows which program is associated with .txt files
ASSOC .txt=txtfile – Associates .txt files with the txtfile file type
ASSOC .mp3=MediaPlayer.Document.11 – Associates MP3 files with Windows Media Player
ASSOC .pdf=AcroExch.Document.DC – Associates PDF files with Adobe Reader
ASSOC .doc= – Removes the file association for .doc files
Important Notes: Changes made with ASSOC require administrator privileges. Use FTYPE to change what program opens a file type.

ATTRIB
Description: Changes the attributes of a single file or directory (read-only, hidden, archive, system).

Basic Syntax:



ATTRIB [+R|-R] [+A|-A] [+S|-S] [+H|-H] [+I|-I] [drive:][path][filename] [/S] [/D]
Common Usage Examples:

ATTRIB +R C:\file.txt – Makes file.txt read-only
ATTRIB -R C:\file.txt – Removes read-only attribute
ATTRIB +H C:\folder – Hides a folder from view
ATTRIB -H C:\folder – Unhides a folder
ATTRIB +S C:\file.txt – Marks file as system file
ATTRIB C:\file.txt – Displays current attributes of the file
ATTRIB +R +A C:\*.txt /S – Makes all .txt files read-only and archive in current folder and subfolders
ATTRIB -H -S C:\Users\Username\AppData\ – Unhides hidden system files
Attribute Codes:

R = Read-only
A = Archive
S = System
H = Hidden
I = Not indexed
/S = Apply to all files in subdirectories
/D = Include directories in processing
CD (CHDIR)
Description: Changes the current working directory or displays the drive letter and folder you're currently in.

Basic Syntax:



CD [/D] [drive:][path]
CD [..]
Common Usage Examples:

CD – Displays the current directory path
CD C:\Users\Documents – Changes to the Documents folder
CD .. – Moves up one directory level
CD \ – Goes to the root directory of the current drive
CD /D D:\Backup – Changes drive and directory simultaneously (requires /D flag)
CD Users\Documents\Projects – Changes to a subdirectory (relative path)
CHDIR C:\Program Files – Alternative syntax using CHDIR instead of CD
Important Notes: Use /D when changing to a directory on a different drive. Without it, you'll only change directories on the current drive.

COMPACT
Description: Shows or changes the compression state of files and directories on NTFS partitions.

Basic Syntax:



COMPACT [/C|/U] [/S[:dir]] [/A] [/I] [/F] [/Q] [filename [...]]
Common Usage Examples:

COMPACT – Displays compression status of files in current directory
COMPACT /C C:\LargeFiles\ – Compresses files in the specified directory
COMPACT /U C:\LargeFiles\ – Uncompresses files in the directory
COMPACT /C /S:C:\Backup – Compresses all files in directory and subdirectories
COMPACT /U /S /A – Uncompresses all files including hidden and system files
COMPACT /C /F /Q C:\*.mp4 – Compresses video files with force flag and quiet mode
COMPACT C:\file.txt – Displays compression status of a single file
Parameter Explanations:

/C = Compress
/U = Uncompress
/S = Process subdirectories
/A = Include hidden and system files
/I = Continue despite errors
/F = Force compression even if file is already partially compressed
/Q = Quiet mode (minimal output)
Important Notes: Only works on NTFS drives. FAT32 and other file systems don't support this command.

COPY
Description: Copies one or more files from one location to another.

Basic Syntax:



COPY [/D] [/V] [/N] [/Y|/-Y] [/Z] [/L] [/A|/B] source [/A|/B] [+ source [/A|/B] [+ ...]] [destination [/A|/B]]
Common Usage Examples:

COPY C:\file.txt D:\ – Copies file.txt from C: drive to D: drive
COPY file.txt file_backup.txt – Creates a copy with a different name in same directory
COPY C:\*.txt D:\ – Copies all .txt files from C: to D:
COPY /Y C:\file.txt D:\ – Copies without prompting if file exists (overwrite)
COPY /-Y C:\file.txt D:\ – Prompts before overwriting existing file
COPY C:\file1.txt + C:\file2.txt C:\combined.txt – Combines multiple files into one
COPY C:\source\*.* D:\destination\ – Copies all files and preserves extensions
COPY /V C:\file.txt D:\ – Copies and verifies the copy was successful
Parameter Explanations:

/D = Allows destination file to be created as decrypted file
/V = Verifies files are written correctly
/N = Uses short filename if available
/Y = Suppresses prompting (assumes yes to overwrite)
/-Y = Prompts before overwriting
/Z = Copies networked files in restartable mode
/L = If source is symbolic link, copy the link itself, not the target
/A = Indicates ASCII text file
/B = Indicates binary file
DEL (ERASE)
Description: Deletes one or more files.

Basic Syntax:



DEL [/P] [/F] [/S] [/Q] [/A:attributes] [drive:][path][filename]
ERASE [/P] [/F] [/S] [/Q] [/A:attributes] [drive:][path][filename]
Common Usage Examples:

DEL C:\file.txt – Deletes file.txt (prompts for confirmation)
DEL /Q C:\file.txt – Deletes without prompting
DEL C:\*.txt – Deletes all .txt files in directory
DEL /S C:\*.tmp – Deletes all .tmp files in directory and subdirectories
DEL /P C:\oldfiles\*.* – Deletes all files with individual confirmation for each
DEL /A:H C:\hidden.txt – Deletes hidden file
DEL /F /S C:\folder\*.* – Force delete all files in folder and subfolders (removes read-only attribute)
ERASE C:\file.txt – Alternative syntax using ERASE instead of DEL
Parameter Explanations:

/P = Prompts for confirmation before deleting each file
/F = Forces deletion of read-only files
/S = Deletes specified files from all subdirectories
/Q = Quiet mode (no prompts)
/A = Selects files by attributes (H=Hidden, S=System, R=Read-only, A=Archive)
Important Notes: Deleted files cannot be recovered from command line. Use caution with wildcards like . which delete all files.

DELTREE
Description: Deletes a directory and all the files and subdirectories within it.

Basic Syntax:



DELTREE [/Y] [drive:][path]
Common Usage Examples:

DELTREE C:\OldFolder – Deletes OldFolder and all its contents (prompts for confirmation)
DELTREE /Y C:\Temp – Deletes Temp folder without prompting
DELTREE C:\Users\Username\Downloads\OldFiles – Deletes nested directory structure
DELTREE /Y D:\Backup\Old_2023 – Force deletes directory on different drive
Parameter Explanations:

/Y = Suppresses confirmation prompt
Important Notes: This command is deprecated in modern Windows versions. Use RD /S /Q or RMDIR /S /Q instead. DELTREE is more dangerous because it's harder to undo.

DIR
Description: Displays a list of files and folders in the current or specified directory, including file size and other information.

Basic Syntax:



DIR [drive:][path][filename] [/A:attributes] [/B] [/C] [/D] [/L] [/N] [/O:sortorder] [/P] [/Q] [/R] [/S] [/T:timefield] [/X] [/4]
Common Usage Examples:

DIR – Lists all files and folders in current directory
DIR C:\Users\Documents – Lists contents of Documents folder
DIR *.txt – Lists only .txt files in current directory
DIR /S – Lists all files in current directory and all subdirectories
DIR /S /B – Lists all files with full path in bare format (no details)
DIR /O:N – Lists files sorted by name
DIR /O:S – Lists files sorted by size
DIR /O:-D – Lists files sorted by date in descending order (newest first)
DIR /A:H – Shows only hidden files
DIR /A:-H – Shows all files except hidden files
DIR /A:D – Shows only directories
DIR /P – Displays output one screen at a time
DIR /L – Displays filenames in lowercase
DIR C:\*.exe /S – Finds all executable files on C: drive and subdirectories
DIR /T:C – Shows file creation time instead of modification time
Parameter Explanations:

/A = Display files with specific attributes (H=Hidden, S=System, D=Directory, A=Archive, R=Read-only)
/B = Bare format (filename only, no additional info)
/C = Display file sizes with thousands separator
/D = Same as wide format, sorted by column
/L = Lowercase display
/N = New long format (filename on right side)
/O = Sort order (N=Name, S=Size, D=Date, G=Directories first, E=Extension, A=Ascending, D=Descending)
/P = Pause after each screen
/Q = Display file owner
/R = Display alternate data streams
/S = Include subdirectories
/T = Time field (C=Created, A=Accessed, W=Written)
/X = Display short (8.3) filenames
/4 = Display year as 4 digits
DIRQUOTA
Description: Manages File Server Resource Manager disk quotas.

Basic Syntax:



DIRQUOTA [action] [parameters]
Common Usage Examples:

DIRQUOTA quota list – Lists all configured quotas
DIRQUOTA quota create /Path:C:\SharedFolder /Limit:1GB – Creates 1GB quota on folder
DIRQUOTA quota delete /Path:C:\SharedFolder – Removes quota from folder
DIRQUOTA quota modify /Path:C:\SharedFolder /Limit:2GB – Changes quota limit
DIRQUOTA quota list /Remote:servername – Lists quotas on remote server
DIRQUOTA autoquota create /Path:C:\SharedFolder /Template:"100 MB Limit" – Creates auto-quota
Important Notes: Requires File Server Resource Manager (FSRM) role to be installed. Primarily used on Windows Server systems.

DISKPART
Description: Creates, manages, and deletes hard drive partitions. Launches interactive utility.

Basic Syntax:



DISKPART
Common Usage Examples (within DISKPART interactive mode):

DISKPART – Launches the DISKPART utility
LIST DISK – Shows all disks on system
SELECT DISK 0 – Selects disk 0 for operations
LIST PARTITION – Shows all partitions on selected disk
CREATE PARTITION PRIMARY SIZE=10240 – Creates 10GB primary partition
DELETE PARTITION – Deletes selected partition
FORMAT FS=NTFS LABEL="MyDrive" – Formats partition with NTFS and label
ASSIGN LETTER=E – Assigns drive letter E: to partition
REMOVE LETTER=E – Removes drive letter assignment
EXTEND SIZE=5120 – Extends partition by 5GB
CONVERT GPT – Converts disk from MBR to GPT format
CLEAN – Removes all partitions from disk
EXIT – Exits DISKPART utility
Important Notes: DISKPART is interactive and requires administrator privileges. Be extremely careful as operations are difficult to undo. Always verify you're working on the correct disk.

EXPAND
Description: Uncompresses CAB (cabinet) files.

Basic Syntax:



EXPAND source_file.cab [destination_folder]
EXPAND source_file.cab -F:filename destination_folder
Common Usage Examples:

EXPAND C:\archive.cab D:\ – Extracts all files from cabinet file to D:
EXPAND C:\install.cab -F:driver.sys D:\Drivers\ – Extracts specific file from cabinet
EXPAND C:\Windows\*.cab C:\Extracted\ – Extracts multiple cabinet files
EXPAND C:\backup.cab – Extracts files to current directory
EXPAND C:\system.cab -F:* D:\System32\ – Extracts all files from cabinet with wildcard
Parameter Explanations:

Source file = Cabinet (.cab) file to extract
Destination = Where to extract files (optional, defaults to current directory)
-F: = Specifies specific file(s) to extract from cabinet
Important Notes: This command only works with .CAB files. For ZIP files, use other utilities or Windows' built-in ZIP support.

FC
Description: Compares two files and displays the differences between them.

Basic Syntax:



FC [/A] [/C] [/L] [/LBn] [/N] [/OFF[LINE]] [/T] [/U] [/W] [/nnnn] file1 file2
Common Usage Examples:

FC file1.txt file2.txt – Compares two text files and shows differences
FC /L C:\version1.txt C:\version2.txt – Compares files in ASCII mode (line by line)
FC /B C:\image1.bin C:\image2.bin – Compares binary files
FC /C file1.txt file2.txt – Ignores case sensitivity in comparison
FC /W file1.txt file2.txt – Ignores whitespace differences
FC /N file1.txt file2.txt – Displays line numbers in output
FC /T file1.txt file2.txt – Doesn't expand tabs to spaces
FC /U C:\config1.ini C:\config2.ini – Treats files as Unicode text files
Parameter Explanations:

/A = Displays only first and last lines of differences (abbreviated)
/B = Binary comparison mode
/C = Case-insensitive comparison
/L = ASCII comparison mode (default for text)
/LBn = Sets maximum number of consecutive differences
/N = Displays line numbers
/OFF[LINE] = Doesn't skip files with offline attribute
/T = Doesn't expand tabs
/U = Unicode file comparison
/W = Compresses whitespace for comparison
/nnnn = Number of lines that must match after difference
FIND
Description: Searches for a text string in a file and displays matching lines.

Basic Syntax:



FIND [/V] [/C] [/N] [/I] [/OFF[LINE]] "string" [[drive:][path]filename[ ...]]
Common Usage Examples:

FIND "error" C:\logfile.txt – Searches for "error" in logfile
FIND /C "warning" C:\system.log – Counts occurrences of "warning"
FIND /N "TODO" C:\script.bat – Displays line numbers with matches
FIND /I "failed" C:\results.txt – Case-insensitive search
FIND /V "success" C:\output.txt – Displays all lines NOT containing "success"
FIND "error" C:\*.txt – Searches multiple text files
TYPE C:\logfile.txt | FIND "critical" – Searches using pipe operator
FIND /N /I "warning" C:\log1.txt C:\log2.txt – Multi-file search with line numbers
Parameter Explanations:

/V = Displays lines NOT containing the string
/C = Displays count of lines containing the string
/N = Displays line numbers with results
/I = Case-insensitive search
/OFF[LINE] = Doesn't skip offline files
Important Notes: FIND is limited to simple text searches. For more complex pattern matching, use FINDSTR instead.

FINDSTR
Description: Searches for strings in files using regular expressions and patterns.

Basic Syntax:



FINDSTR [/B] [/E] [/L] [/R] [/S] [/I] [/X] [/V] [/N] [/M] [/O] [/P] [/F:file] [/C:string] [/G:file] [/D:dir list] [/OFF[LINE]] strings [[drive:][path]filename[ ...]]
Common Usage Examples:

FINDSTR "error" C:\logfile.txt – Basic string search
FINDSTR /R "^ERROR" C:\log.txt – Finds lines starting with ERROR (regex)
FINDSTR /I /S "warning" C:\logs\ – Case-insensitive recursive search
FINDSTR /C:"exact phrase" C:\document.txt – Searches for exact phrase with spaces
FINDSTR /R "[0-9]" C:\data.txt – Finds any line containing digits
FINDSTR /V "success" C:\output.txt – Lines NOT containing "success"
FINDSTR /N /I "failed\|error" C:\results.txt – Multiple search terms (OR)
FINDSTR /M "pattern" C:\*.txt – Displays only filenames with matches
FINDSTR /R "^[A-Z]" C:\file.txt – Finds lines starting with uppercase letters
FINDSTR /S /I "TODO\|FIXME" C:\project\ – Searches subdirectories for multiple patterns
Parameter Explanations:

/B = Matches pattern at beginning of line
/E = Matches pattern at end of line
/L = Uses literal string (not regex)
/R = Uses regular expressions (default)
/S = Searches subdirectories
/I = Case-insensitive
/X = Matches entire line
/V = Lines NOT containing pattern
/N = Displays line numbers
/M = Displays only filename
/O = Displays character offset before each match
/P = Skips files with non-printable characters
/F:file = Reads search patterns from file
/C:string = Uses literal string (spaces preserved)
/G:file = Gets patterns from file
/D:dir list = Searches specified directories
/OFF[LINE] = Doesn't skip offline files
Important Notes: FINDSTR is more powerful than FIND. It supports regular expressions for complex pattern matching.

FORMAT
Description: Formats a disk for use with Windows, erasing all data.

Basic Syntax:



FORMAT volume [/FS:file-system] [/V:label] [/Q] [/A:size] [/C] [/X] [/Y]
Common Usage Examples:

FORMAT D: – Formats D: drive with prompts
FORMAT D: /FS:NTFS /V:MyDrive /Q – Quick format to NTFS with label
FORMAT D: /FS:FAT32 /Q – Quick format to FAT32
FORMAT E: /Q /Y – Quick format without confirmation
FORMAT D: /A:4096 – Formats with 4KB allocation unit size
FORMAT D: /FS:NTFS /C – Formats NTFS and enables file compression
FORMAT X: /FS:exFAT /V:USB_Drive – Formats USB drive to exFAT
FORMAT D: /FS:NTFS /A:512 – Formats with 512-byte allocation units
Parameter Explanations:

/FS:file-system = Specifies file system (FAT32, NTFS, exFAT)
/V:label = Specifies volume label
/Q = Quick format (doesn't overwrite data sectors)
/A:size = Specifies allocation unit size
/C = Files created on new volume will be compressed by default
/X = Forces dismounting of volume before formatting
/Y = Suppresses confirmation prompt
Important Notes: FORMAT erases all data on the disk. Always verify you're formatting the correct drive. Quick format is faster but less secure.

FTYPE
Description: Displays or modifies file extension file type associations.

Basic Syntax:



FTYPE [fileType[=[openCommandString]]]
Common Usage Examples:

FTYPE – Displays all file types and their associated commands
FTYPE txtfile – Shows what program opens .txt files
FTYPE htmlfile – Shows associated HTML file type
FTYPE txtfile="Notepad.exe" %%1 – Associates txtfile type with Notepad
FTYPE pdffile="C:\Program Files\Adobe\Acrobat DC\Acrobat.exe" %%1 – Associates PDF type
FTYPE = – Deletes file type association
FTYPE jpegfile="C:\Program Files\Windows Photo Viewer\PhotoViewer.dll" %%1 – Associates image type
Parameter Explanations:

fileType = The file type to query or modify
openCommandString = Command to execute when file type is opened
%%1 = Represents the filename being opened
%%* = Represents all parameters
Important Notes: Use ASSOC to change file extensions, and FTYPE to change what program opens the file type. Both commands require administrator privileges.

LABEL
Description: Edits a disk label or volume name.

Basic Syntax:



LABEL [drive:][label]
LABEL [/MP] [drive:][label]
Common Usage Examples:

LABEL – Displays current volume label and prompts for new one
LABEL D: – Displays and allows changing D: drive label
LABEL D: MyBackup – Sets D: drive label to "MyBackup"
LABEL C: Work_Files_2024 – Sets C: drive label with underscore
LABEL D: – Removes label from D: drive (space after colon)
LABEL /MP D: – Changes label of multi-partition drive
LABEL E: USB_Storage – Labels USB drive
Parameter Explanations:

drive: = Drive letter to label
label = New label name (max 32 characters for NTFS, 11 for FAT32)
/MP = For multi-partition removable media
Important Notes: Volume labels are optional and used for identification. NTFS supports longer labels than FAT32.

MAKECAB
Description: Creates .CAB (cabinet) files for file compression and archiving.

Basic Syntax:



MAKECAB [/V[n]] [/R] [/D var=value ...] [/L dir] source [destination]
MAKECAB [/V[n]] [/R] [/D var=value ...] /F file.ddf
Common Usage Examples:

MAKECAB C:\file.txt C:\archive.cab – Creates cabinet file from single file
MAKECAB /R C:\folder\*.* C:\backup.cab – Recursively archives folder contents
MAKECAB /V C:\document.docx C:\archive.cab – Creates cabinet with verbose output
MAKECAB /L C:\output C:\source.txt C:\archive.cab – Specifies output directory
MAKECAB /F directives.ddf – Creates cabinet using directive file
MAKECAB /V2 C:\data.bin C:\compressed.cab – Verbose mode level 2
Parameter Explanations:

/V[n] = Verbose output (optional level 1-3)
/R = Recurse subdirectories
/D var=value = Defines variable for directive file
/L dir = Location for cabinet file
/F file.ddf = Uses directive file for complex operations
source = File or folder to compress
destination = Output cabinet file
Important Notes: MAKECAB creates .CAB files which are useful for distribution and archiving. Use EXPAND to extract.

MD (MKDIR)
Description: Creates a new directory or folder.

Basic Syntax:



MD [drive:]path
MKDIR [drive:]path
Common Usage Examples:

MD NewFolder – Creates folder in current directory
MD C:\Users\Documents\Projects – Creates folder in specified path
MD C:\Backup\2024\January – Creates nested directories
MKDIR D:\MyData – Alternative syntax using MKDIR
MD C:\Program Files\MyApp\Data – Creates folder in Program Files
MD "C:\My Documents\New Project" – Creates folder with spaces in name
MD C:\temp && CD C:\temp – Creates folder and changes to it
Parameter Explanations:

drive: = Drive letter (optional, defaults to current drive)
path = Full or relative path to new directory
Important Notes: You can create nested directories in one command. Parent directories must exist unless you're creating the full path.

MKLINK
Description: Creates a symbolic link to a file or directory.

Basic Syntax:



MKLINK [[/D] | [/H] | [/J]] Link Target
Common Usage Examples:

MKLINK C:\link.txt C:\original.txt – Creates symbolic link to file
MKLINK /D C:\LinkFolder C:\RealFolder – Creates symbolic link to directory
MKLINK /H C:\hardlink.txt C:\original.txt – Creates hard link to file
MKLINK /J C:\JunctionFolder C:\RealFolder – Creates directory junction
MKLINK C:\Shortcuts\file.txt D:\Documents\file.txt – Links across drives
MKLINK /D "C:\Program Files\AppLink" "D:\Applications\MyApp" – Links with spaces
Parameter Explanations:

/D = Creates directory symbolic link
/H = Creates hard link (file only)
/J = Creates directory junction
Link = Name of symbolic link to create
Target = File or directory being linked to
Important Notes: Requires administrator privileges. Symbolic links point to targets; hard links are direct copies of file references. Junctions only work with directories.

MOVE
Description: Moves files from one folder to another, or renames files and directories.

Basic Syntax:



MOVE [/Y|/-Y] [drive:][path]filename1[,...] destination
Common Usage Examples:

MOVE C:\file.txt D:\ – Moves file to different drive
MOVE file.txt renamed.txt – Renames file in same directory
MOVE C:\OldFolder C:\NewFolder – Renames directory
MOVE /Y C:\file.txt D:\ – Moves without prompting if destination exists
MOVE /-Y C:\file.txt D:\ – Prompts before overwriting
MOVE C:\folder\*.txt D:\archive\ – Moves all .txt files to another folder
MOVE C:\OldName D:\NewLocation\NewName – Moves and renames simultaneously
Parameter Explanations:

/Y = Suppresses prompting for confirmation
/-Y = Prompts before overwriting
filename1 = Source file or directory
destination = Target location or new name
Important Notes: MOVE is used for both moving and renaming. Cannot move across file systems in older Windows versions.

RD (RMDIR)
Description: Deletes a directory or folder.

Basic Syntax:



RD [/S] [/Q] [drive:][path]
RMDIR [/S] [/Q] [drive:][path]
Common Usage Examples:

RD C:\EmptyFolder – Deletes empty directory
RD /S C:\OldFolder – Deletes directory and all contents (with prompt)
RD /S /Q C:\Temp – Deletes directory and contents without prompting
RMDIR /S C:\Backup – Alternative syntax using RMDIR
RD /S /Q C:\Users\Downloads\OldFiles – Removes nested directory structure
RD /S C:\folder\* – Deletes all subdirectories
Parameter Explanations:

/S = Removes directory and all contents recursively
/Q = Quiet mode (no confirmation)
drive: = Drive letter (optional)
path = Path to directory to delete
Important Notes: Directory must be empty unless /S flag is used. Use /S /Q with caution as it permanently removes all contents.

REN (RENAME)
Description: Renames a file or files.

Basic Syntax:



REN [/E] [/N] [/P] [/Q] [/S] [/T] [drive:][path]filename1 filename2
RENAME [/E] [/N] [/P] [/Q] [/S] [/T] [drive:][path]filename1 filename2
Common Usage Examples:

REN oldname.txt newname.txt – Renames file in current directory
REN C:\file.txt backup.txt – Renames file with path
REN *.txt *.bak – Renames all .txt files to .bak extension
REN document.docx document_final.docx – Renames with descriptive name
REN /S C:\*.tmp *.old – Renames all .tmp files in directory and subdirectories
RENAME "old file name.txt" "new file name.txt" – Renames files with spaces
REN C:\data_*.txt data_backup_*.txt – Uses wildcards in rename
Parameter Explanations:

/E = Enables extended renaming features
/N = Shows what would be renamed without making changes
/P = Prompts for confirmation before each rename
/Q = Quiet mode (no prompts)
/S = Includes subdirectories
/T = Tests the operation without executing
filename1 = Original filename
filename2 = New filename
Important Notes: Cannot move files between directories with REN. Use MOVE for that. Wildcards can be used for batch renaming.

REPLACE
Description: Replaces or updates one file with another.

Basic Syntax:



REPLACE [drive1:][path1]filename [drive2:][path2] [/A] [/P] [/R] [/W] [/U]
Common Usage Examples:

REPLACE C:\newfile.txt D:\ – Replaces file in destination directory
REPLACE C:\backup\*.* D:\current\ /S – Replaces multiple files recursively
REPLACE C:\update.exe C:\Program Files\App\ /P – Replaces with confirmation
REPLACE C:\version2.dll C:\System32\ /U – Replaces only if source is newer
REPLACE C:\data.ini C:\config\ /R – Replaces read-only files
REPLACE /A C:\newfiles\*.* D:\ – Adds files that don't exist in destination
Parameter Explanations:

/A = Adds new files to destination instead of replacing
/P = Prompts for confirmation before replacement
/R = Replaces read-only files
/S = Includes subdirectories
/U = Replaces only if source is newer than destination
/W = Waits for user to insert disk
Important Notes: REPLACE is useful for updating files. The /U flag is helpful for version control.

ROBOCOPY
Description: Provides robust file and folder copying with advanced options for backups and synchronization.

Basic Syntax:



ROBOCOPY source destination [file(s)] [options]
Common Usage Examples:

ROBOCOPY C:\source D:\destination – Copies all files from source to destination
ROBOCOPY C:\source D:\destination /E – Copies directory tree including empty directories
ROBOCOPY C:\source D:\destination /MIR – Mirrors directory (deletes extra files in destination)
ROBOCOPY C:\source D:\destination *.txt – Copies only .txt files
ROBOCOPY C:\source D:\destination /S /E /COPY:DAT – Copies with data, attributes, timestamps
ROBOCOPY C:\source D:\destination /MIR /R:3 /W:10 – Mirrors with 3 retries and 10-second waits
ROBOCOPY C:\source D:\destination /S /MAXAGE:30 – Copies files modified in last 30 days
