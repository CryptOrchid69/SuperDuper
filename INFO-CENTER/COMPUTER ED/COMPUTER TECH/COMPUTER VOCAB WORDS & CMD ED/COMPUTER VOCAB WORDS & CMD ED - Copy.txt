COMPREHENSIVE COMPUTER VOCABULARY LIST-HARDWARE BASICS

Motherboard – The main circuit board everything else connects to; the backbone of your computer system.

CPU (Central Processing Unit) – The "brain" that processes instructions and controls all computer operations. Faster CPUs mean better performance.

RAM (Random Access Memory) – Temporary storage where active programs and data are kept for quick access. More RAM enables better multitasking.

Hard Drive – Long-term storage for files, programs, and the operating system. Data persists even when powered off.

SSD (Solid State Drive) – Faster storage than traditional hard drives with no moving parts; makes computers boot up and load programs much quicker.

NVMe (Non-Volatile Memory Express) – An extremely fast SSD interface that provides the quickest response times.

GPU (Graphics Processing Unit) – A specialized processor optimized for graphics; critical for gaming, 3D work, and video editing.

PSU (Power Supply Unit) – Converts AC power from wall outlets to DC power that computer components need.

PCIe (PCI Express) – A versatile high-speed connector for add-in cards like GPUs, SSDs, and capture cards.

Form Factor – Refers to a computer's physical size and shape (e.g., laptop vs. desktop tower).

CMOS (Complementary Metal-Oxide Semiconductor) – A chip that stores key settings like system time and hardware configuration, powered by a coin battery.

BIOS/UEFI – Low-level software that runs when you first start your computer; handles booting the OS.

POST (Power-On Self Test) – A series of quick checks the computer runs at startup to verify hardware is working.

Heatsink – A block of metal fins that draws heat away from the CPU or GPU, usually topped with a fan.


ESSENTIAL PERIPHERALS

Monitor – The display screen showing computer output; comes in different sizes, resolutions, and panel types (LCD, LED, OLED).

Keyboard – Input device for typing and giving your computer commands.

Mouse – Pointing device that lets you precisely interact with items on the screen.

Speakers/Headphones – Audio output devices for listening to sound and music.

Microphone – Input device for voice commands, calls, and audio recording.

Webcam – Small video camera used for video calls and conferences; some have infrared for facial recognition.

Printer – Device for producing physical copies of documents and photos.


SOFTWARE ESSENTIALS

OS (Operating System) – Main software that manages your computer's hardware and other software (Windows, macOS, Linux).

Application – A program designed for a specific task, like a web browser, photo editor, or game.

Web Browser – Software that allows you to access and view websites on the internet (Chrome, Firefox, Edge, Safari).

File – A discrete package of data, such as a document, photo, or program.

Folder/Directory – A virtual container for organizing files; folders can contain other folders.

Icon – A small graphic that represents a file, folder, or program.

Antivirus – Software that detects and removes malware like viruses, spyware, and ransomware.

Firewall – Monitors incoming and outgoing network traffic to protect your system and data.

Drivers – Software that lets your OS communicate with a particular piece of hardware.

Firmware – Permanent software programmed into read-only memory on devices like routers and IoT gadgets.

GUI (Graphical User Interface) – How most modern operating systems and apps present themselves using windows, icons, and menus.

CLI (Command Line Interface) – Text-based interface for controlling a computer by typing commands (also called Terminal or Command Prompt).

System Tray – Small area (usually bottom-right on Windows) that holds status icons and background applications.

Control Panel – Collection of tools and settings for configuring your Windows system.

Terminal – Text-based interface for running commands; called Command Prompt on Windows and Terminal on Mac/Linux.

Package Manager – Tool for easily installing, updating, and managing software; essential for Linux users.

Task Manager – Shows information about running processes and resource usage; helps identify unresponsive programs.

Hidden Files – Files configured not to show up in regular file browsers; usually system files.

Shortcut – A small file that points to another file, folder, or program for quick access.

Permissions – Settings that control whether a user can view, edit, or execute a particular file.

Temp Files – Temporary files programs generate in the background; can usually be safely deleted.

NAS (Network Attached Storage) – A dedicated file server providing storage over a network.

RAID – Combining multiple drives to improve performance and/or fault tolerance.

USB Flash Drive – Small, portable storage device that plugs into a USB port.

External Drive – Hard drive or SSD in a case that connects to a computer, usually via USB.

INTERNET & WEB

Web – Short for World Wide Web; the collective network of public websites linked via hyperlinks.

HTTP – Hypertext Transfer Protocol that powers the web.

HTTPS – Secure version of HTTP with encryption.

SSL (Secure Sockets Layer) – Encryption protocol used to secure data sent over the internet.

URL (Uniform Resource Locator) – Web address specifying the location of a resource (e.g., www.google.com).

Download – Receiving data from a remote system.

Cloud – Services provided over the internet rather than locally on your device.

Hosting – Paying a company to store your website's files and data on a server.

Client – Your web browser; the program that requests resources from a web server.

Server – Powerful computer that stores websites and apps, serving them to client devices.


NETWORKING

IP Address – Unique string of numbers identifying each device on a network (like a virtual return address).

MAC Address – Permanent ID number assigned to a device's network card.

LAN (Local Area Network) – Small network confined to one area, like a home or office.

Ethernet – Wired networking technology for connecting devices in a LAN using cables.

Wi-Fi – Wireless networking based on 802.11 standards.

Router – Device that routes data between networks.

Modem – Converts signals between analog (cable/phone lines) and digital (Ethernet).

Switch – Connects multiple wired devices on a network so they can communicate.

Port – Virtual endpoint for network communication; different services use specific port numbers.

DNS (Domain Name System) – Translates human-friendly domain names into IP addresses.

DHCP (Dynamic Host Configuration Protocol) – Automatically assigns IP addresses to devices on a network.

Subnet Mask – Defines which part of an IP address identifies the network vs. the device.

NAT (Network Address Translation) – Lets multiple devices share one public IP address.

VLAN (Virtual LAN) – Partitions a physical network into separate virtual networks.

QoS (Quality of Service) – Prioritizes certain types of network traffic for smoother performance.

Throughput – Actual amount of data sent over a connection in a given time.

Latency – Time it takes data to travel from source to destination; lower is better.

Jitter – Variation in latency that can cause choppy audio and laggy video.

Packet Loss – Percentage of data packets lost in transit; can degrade voice and video quality.

Redundancy – Multiple paths for data to travel; helps maintain connectivity if one path fails.


SECURITY

Encryption – Scrambling data so it can only be read with a special key.

Authentication – Proving a user's or device's identity, usually with username and password.

2FA (Two-Factor Authentication) – Extra login step beyond password, like a code from an app.

Password Manager – Encrypted vault for storing and generating strong passwords.

Privacy Settings – Options to control how your data is collected and used.

VPN (Virtual Private Network) – Encrypts your internet traffic and masks your IP address.

Backup – Spare copy of important data in case the original is lost or damaged.

Phishing – Tricking people into revealing sensitive info by posing as a trusted entity.

Spam – Unsolicited bulk messages, usually email.

Malware – Catch-all term for malicious software like viruses, spyware, and ransomware.

Trojan – Malware disguised as legitimate software.

Virus – Malware that spreads by copying itself like a biological virus.

Worm – Self-replicating virus that spreads over networks without needing another program.

Spyware – Malware that spies on computer activity and collects personal data.

Ransomware – Malware that encrypts your files and demands payment for the decryption key.

Adware – Malware that bombards you with unwanted ads.

Rootkit – Malware that burrows deep into your system to hide itself.

Bot – Automated malware letting hackers remotely control your computer.

DDoS (Distributed Denial of Service) – Attack where botnets flood a target system to overwhelm it.

Zero-Day – Vulnerability exploited before the software maker can fix it.

Social Engineering – Exploiting human psychology rather than technical vulnerabilities.

Brute-Force Attack – Attempting to guess a password by trying every possible combination.

Hash – Digital fingerprint of data used to verify files haven't been tampered with.

Salting – Adding random data to a hash to make it harder to crack.


MULTIMEDIA

Ripping – Copying audio or video data from one format to another.

Aspect Ratio – Width-to-height ratio of a video or image (4:3 for old TVs, 16:9 for modern ones).

Resolution – Number of pixels in an image or video frame; higher means more detail.

Refresh Rate – How many times per second a screen completely redraws itself.

Frame Rate – Number of individual images making up one second of video (films use 24fps).

Bit Rate – Number of bits (data) processed per second; higher means better quality but larger files.

HDR (High Dynamic Range) – Heightens a picture's dynamic range (contrast) for richer images.

Surround Sound – Audio from multiple speakers positioned around you (5.1, 7.1, Dolby Atmos).

TIPS FOR USING CMD COMMANDS

Get Help - Type HELP or HELP [command] to see available commands and their usage

Use /? Flag - Most commands support /? to display detailed help information

Use Pipes - Combine commands with | to send output from one command to another

Use Redirection - Use > to redirect output to a file or >> to append

Batch Files - Create .bat or .cmd files to automate multiple commands

Run as Administrator - Right-click Command Prompt and select "Run as Administrator" for elevated privileges

Tab Completion - Press Tab to auto-complete file and folder names
