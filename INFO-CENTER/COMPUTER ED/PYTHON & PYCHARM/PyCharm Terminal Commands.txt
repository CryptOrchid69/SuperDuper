COMPLETE PYCHARM TERMINAL COMMAND REFERENCE
Windows 11 - PowerShell-first edition
Updated: June 18, 2026

IMPORTANT


PyCharm can use PowerShell, Command Prompt, Git Bash, or another shell.
The commands in this file use PowerShell unless a different shell is named.

Run one command at a time. Read a command before running it.
Replace example names such as PACKAGE, script.py, and FolderName.
Put quotation marks around paths containing spaces.

Prefer:

py -m pip ...

instead of:

pip ...

Using "py -m pip" helps ensure that pip belongs to the selected Python.

Commands containing Remove-Item, taskkill, Stop-Process, git clean, or
uninstall can delete data or stop programs. Use them only when intended.


SECTION 1 - NAVIGATION AND TERMINAL BASICS


Show the current folder:

Get-Location

Short PowerShell alias:

pwd

Change to a folder:

Set-Location "C:\Path\To\Folder"

Short form:

cd "C:\Path\To\Folder"

Open the Desktop folder:

cd "$env:USERPROFILE\Desktop"

Open the New Teacher 2 folder:

cd "$env:USERPROFILE\Desktop\New Teacher 2"

Move up one folder:

cd ..

Move up two folders:

cd ..\..

Move to the root of the current drive:

cd \

Return to the previous location:

Pop-Location

Temporarily save the current location and move elsewhere:

Push-Location "C:\Path\To\Folder"

List files and folders:

Get-ChildItem

Short forms:

dir
ls

List hidden items:

Get-ChildItem -Force

List only files:

Get-ChildItem -File

List only folders:

Get-ChildItem -Directory

List items recursively:

Get-ChildItem -Recurse

List Python files recursively:

Get-ChildItem -Recurse -Filter *.py

Clear the terminal:

Clear-Host

Short form:

cls

Display previous PowerShell commands:

Get-History

Repeat a history entry:

Invoke-History 5

Show help for a PowerShell command:

Get-Help Get-ChildItem

Show detailed help with examples:

Get-Help Get-ChildItem -Full

Find commands by name:

Get-Command *process*

Exit the terminal:

exit


SECTION 2 - FILE AND FOLDER COMMANDS


Create an empty text file:

New-Item -ItemType File -Path "file.txt"

Create or replace a text file with text:

Set-Content -Path "file.txt" -Value "Hello"

Add text to the end of a file:

Add-Content -Path "file.txt" -Value "Another line"

Read a text file:

Get-Content -Path "file.txt"

Read the first 20 lines:

Get-Content -Path "file.txt" -TotalCount 20

Read the last 20 lines:

Get-Content -Path "file.txt" -Tail 20

Monitor new lines written to a log:

Get-Content -Path "app.log" -Wait

Create a folder:

New-Item -ItemType Directory -Path "FolderName"

Short form:

mkdir "FolderName"

Create nested folders:

New-Item -ItemType Directory -Path "Parent\Child" -Force

Copy a file:

Copy-Item -Path "source.txt" -Destination "copy.txt"

Copy and replace an existing file:

Copy-Item -Path "source.txt" -Destination "copy.txt" -Force

Copy a folder and its contents:

Copy-Item -Path "SourceFolder" -Destination "BackupFolder" -Recurse

Move a file:

Move-Item -Path "file.txt" -Destination "C:\Destination"

Rename a file:

Rename-Item -Path "old.txt" -NewName "new.txt"

Show full file information:

Get-Item -Path "file.txt" | Format-List *

Show file size and modified date:

Get-Item -Path "file.txt" | Select-Object FullName,Length,LastWriteTime

Check whether a path exists:

Test-Path "C:\Path\To\File.txt"

Resolve a path to its absolute form:

Resolve-Path ".\file.txt"

Open the current folder in File Explorer:

explorer .

Open a specific folder in File Explorer:

explorer "C:\Path\To\Folder"

Open a text file with its default program:

Start-Process "file.txt"

CAUTION - delete one file:

Remove-Item -LiteralPath "file.txt"

CAUTION - delete an empty folder:

Remove-Item -LiteralPath "FolderName"

CAUTION - delete a folder and everything inside it:

Remove-Item -LiteralPath "FolderName" -Recurse -Force

SECTION 6 - VIRTUAL ENVIRONMENTS


Create a virtual environment:

py -m venv .venv

Create it and upgrade core dependencies:

py -m venv .venv --upgrade-deps

Activate it in PowerShell:

.\.venv\Scripts\Activate.ps1

Activate it in Command Prompt:

.\.venv\Scripts\activate.bat

Deactivate it:

deactivate

Show whether a virtual environment is active:

python -c "import sys; print(sys.prefix != sys.base_prefix)"

Show the active Python executable:

python -c "import sys; print(sys.executable)"

Install requirements inside the active environment:

python -m pip install -r requirements.txt

Run the environment's Python without activating it:

.\.venv\Scripts\python.exe script.py

Run the environment's pip without activating it:

.\.venv\Scripts\python.exe -m pip list

If PowerShell blocks Activate.ps1, allow locally created scripts for the
current user:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

CAUTION - remove a disposable virtual environment:

Remove-Item -LiteralPath ".venv" -Recurse -Force

Virtual environments should be recreated instead of copied or moved.


SECTION 7 - PYINSTALLER AND WINDOWS EXE BUILDS


Install or upgrade PyInstaller:

py -m pip install --upgrade pyinstaller

Show the installed PyInstaller version:

py -m PyInstaller --version

Show PyInstaller help:

py -m PyInstaller --help

Build a normal one-folder application:

Build one executable file:

Build a GUI app without a console window:

py -m PyInstaller --noconsole --onefile script.py

Choose the executable name:

py -m PyInstaller --noconsole --onefile --name MY_APP script.py

Add a Windows icon:

py -m PyInstaller --noconsole --onefile --name MY_APP --icon "APP.ico" script.py

Clean old PyInstaller cache before building:

py -m PyInstaller --clean --noconsole --onefile --name MY_APP script.py

Overwrite an existing build without confirmation:

Include an entire package and its data:

py -m PyInstaller --collect-all PACKAGE script.py

Include a hidden import:

py -m PyInstaller --hidden-import PACKAGE.MODULE script.py

Add one data file on Windows:

Add a data folder on Windows:

py -m PyInstaller --add-data "FILES;FILES" script.py

Build from an existing specification file:

py -m PyInstaller MY_APP.spec

Display detailed import/build information:

py -m PyInstaller --log-level DEBUG script.py

Exact upgraded TEACHER build used in New Teacher 2:

cd "$env:USERPROFILE\Desktop\New Teacher 2"

py -m PyInstaller --clean --noconsole --onefile --name TEACHER --icon "TEACHER.ico" --collect-all PyQt6 --collect-all sympy TEACHER.py

Copy the finished TEACHER.exe from dist to the current folder:

Copy-Item -LiteralPath ".\dist\TEACHER.exe" -Destination ".\TEACHER.exe" -Force

Build TEACHER without SymPy for an older non-calculator source:

py -m PyInstaller --clean --noconsole --onefile --name TEACHER --icon "TEACHER.ico" --collect-all PyQt6 TEACHER.py

Typical build output locations:

.\build
.\dist
.\MY_APP.spec

The usable executable is normally:

.\dist\MY_APP.exe

Check whether the executable exists:

Test-Path ".\dist\MY_APP.exe"

Show executable size and date:

Get-Item ".\dist\MY_APP.exe" |
    Select-Object FullName,Length,LastWriteTime

Compare two executables by SHA-256 hash:

Get-FileHash -Algorithm SHA256 ".\dist\MY_APP.exe"
Get-FileHash -Algorithm SHA256 ".\MY_APP.exe"

The files are identical when their SHA-256 hash values are identical.

CAUTION - remove old build output before rebuilding:

Remove-Item -LiteralPath ".\build" -Recurse -Force
Remove-Item -LiteralPath ".\dist" -Recurse -Force

SECTION 12 - PYCHARM COMMAND-LINE LAUNCHER


The official Windows executables are normally:

pycharm64.exe
pycharm.bat

They work from any folder only when PyCharm's bin folder or the JetBrains
Toolbox scripts folder is included in PATH.

Launch PyCharm:

pycharm64.exe

Open the current folder as a project:

pycharm64.exe .

Open a specific folder:

pycharm64.exe "C:\Projects\My Project"

Open a file:

pycharm64.exe "C:\Projects\My Project\script.py"

Open a file and wait until it is closed:

pycharm64.exe --wait "script.py"

Start without the splash screen:

pycharm64.exe nosplash

Start without reopening previous projects:

pycharm64.exe dontReopenProjects

Start without third-party plugins:

pycharm64.exe disableNonBundledPlugins

Open PyCharm's difference viewer:

pycharm64.exe diff "old.py" "new.py"

Format files using PyCharm code style:

pycharm64.exe format "script.py"

Inspect a project:

pycharm64.exe inspect "C:\Project" "C:\InspectionProfile.xml" "C:\Results"

JetBrains Toolbox normally places launch scripts here:

$env:LOCALAPPDATA\JetBrains\Toolbox\scripts

Find a configured PyCharm launcher:

Get-Command pycharm64.exe,pycharm.bat -ErrorAction SilentlyContinue

NOTE:
"charm" is not the standard official Windows command unless you or a tool
created a launcher with that custom name.

SECTION 16 - HASHES, CHECKSUMS, AND FILE COMPARISON


Calculate a SHA-256 hash:

Get-FileHash -Algorithm SHA256 "file.exe"

Calculate an MD5 hash:

Get-FileHash -Algorithm MD5 "file.exe"

Compare two text files:

Compare-Object (Get-Content "old.txt") (Get-Content "new.txt")

Compare file hashes:

$first = (Get-FileHash "first.exe").Hash
$second = (Get-FileHash "second.exe").Hash
$first -eq $second

Show True only when the files have identical hashes.
